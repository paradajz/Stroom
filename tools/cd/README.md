# CD tools

- [Listener](listener/README.md): receive CD audio from the PS2, with discovery and stream diagnostics.
- [Recognition service](recognition/README.md): supply album and track labels and cover art, with configuration and hosting instructions.
- [Recognition HTTP protocol](recognition/http-protocol.md): implement a client for the hosted service.

The listener and recognition service run independently and can run together. Local PS2 CD playback works with neither PC tool running.
